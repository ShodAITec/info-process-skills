# 示例产出

这里是两份真实运行的产出，用于展示各技能的效果。
每份包含 `report.md`（正文）、`report.html`（单文件离线版）、`run.json`（用量、来源清单、质检结果）。

全部由 `deepseek-v4.1-flash`（TheHive）生成，单份约 3–5 分钟、$0.3。

| 示例 | 技能 | 说明 |
| --- | --- | --- |
| `ai-industry-hotel/` | ai-industry-deep-insight | AI × 酒店管理行业深度洞察（9 章结构，269 个来源） |
| `tech-selection-vectordb/` | tech-selection | 向量数据库选型评估（含 TCO 与加权评分矩阵） |

## 怎么看

- **引用格式**：正文只写 `[N]`，完整网址在文末「参考来源」。HTML 版里 `[N]` 可点击跳转。
- **`run.json`** 里有 `citations`（引用可追溯率）与 `reportEval`（成稿质检评分），
  这两项是系统自己对产出质量的判断，可以用来对照正文读。
- 报告里的事实性内容**请以原文链接为准**——自动生成的内容需要人工复核后才能对外使用。

## 关于 `reportEval`

示例的成稿评审多为 `revise` 而非 `pass`。这是刻意保留的：
评审器被设计得偏严格，会主动挑出证据等级标注不一致、单一来源支撑关键结论之类的问题。
我们认为展示一份带着已知瑕疵、且瑕疵被系统自己标注出来的产出，
比展示一份看起来完美的报告更有参考价值——**这套系统的卖点不是"生成得好"，是"知道自己哪里不好"**。

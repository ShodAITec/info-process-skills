# Domain Archetypes

| Archetype | 典型行业 | 研究主线 | Evidence 更看重什么 |
|---|---|---|---|
| Continuous Lifecycle | 软件、运维 | 生命周期 + Runtime Feedback | Production Workflow / DORA-like KPI |
| Engineering Design Lifecycle | PCB、机械、芯片 | 设计 + 仿真 + 验证 + 制造 | Prototype / Yield / Respins |
| Scientific R&D Lifecycle | 生物医药、材料 | 科研假设 + 模型 + 实验 + 验证 | Prospective Wet Lab / Translational Evidence |
| Regulated Professional Service | 法律、审计、合规 | Matter + Evidence + Rule + Judgment | Accuracy / Trace / Professional Responsibility |
| Content & Media Lifecycle | 自媒体、营销 | 创作 + 生产 + 分发 + 反馈 | Production Efficiency / Engagement / Revenue |
| Education / Coaching Journey | 教育、培训 | 诊断 + 教学 + 练习 + 评价 + 个性化 | Learning Outcome / Teacher Time |
| Travel / Service Operations | 文旅、酒店 | 发现 + 规划 + 预订 + 服务 + 留存 | Conversion / Service Cost / CSAT |
| Transaction / Operations Network | 零售、供应链、金融运营 | 预测 + 决策 + 交易 + 履约 + 风险 | Cost / Accuracy / Throughput / Risk |

选择规则：如果行业包含多个范式，先选一个主范式，再注明次范式。不要为了套模板把行业主流程改写成 AI 技术术语。

# Regulation / Standards → System Requirement Mapping

Chapter 7 不得只罗列法规、标准、职业规范或安全风险。

每个重要约束都要回答：

| Constraint | 影响什么业务/风险 | System Requirement | Human Gate |
|---|---|---|---|

常见 System Requirement：
IAM、Data Boundary、Retention、Audit Trail、Source Trace、Citation Verification、Version Control、Sandbox、Rollback、Approval Gate、Ethical Wall、Change Control。

目标：

> **解释外部规则如何真正改变 AI 系统架构与自主化边界。**

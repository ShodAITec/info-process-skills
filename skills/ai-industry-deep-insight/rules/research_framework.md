# Research Framework v1.5.0

研究阶段和报告阶段分开：

## 研究阶段
Strategic Question → Industry Baseline → Main Process → Artifact/Role/Toolchain/KPI → AI Capability → Academic/Industry/Commercial Scan → Candidate Findings → Core Judgments → Traceability Matrix → Deep Evidence → Constraints → Autonomy → Economics。

## 报告阶段
Core Judgments → Process × Capability → Scenarios → Progress → Products/Cases/Evidence → Human/Organization → Regulation/Standards/Risk → Autonomy → KPI/Landing → Final Validation。

原则：

> **研究可以 Bottom-up，呈现必须 Top-down。**

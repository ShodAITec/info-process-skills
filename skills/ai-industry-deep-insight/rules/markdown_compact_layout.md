# Markdown Compact Layout

## Mandatory Rule

同一语义标签下的 **2 项及以上短语型、同层级内容**，若无需独立证据、引用、解释或子层级，默认合并成一行并使用中文顿号 `、`。

示例：

`**特征**：需要多步骤、调用多个信息源、输出有模板、可以逐项验证、失败可发现、人最终审批。`

`**典型任务**：尽调、合同审查、法律研究、大型卷宗分析、知识检索、新法影响分析。`

数字编号只在以下情况保留：真实流程顺序、优先级、排名、逐条核心判断、逐项引用。

普通枚举不得为了“看起来结构化”拆成多行编号。

## Keep Bullets Only When
每项有独立解释/证据/引用、存在子层级、单项较长、需要逐项比较、合并后明显降低可读性。

## Vertical Density Check
交付前检查：是否存在连续短 Bullet、每行只有一个名词/短语、可横排的编号枚举、重复近义项。发现则压缩。

原则：**短项横排，长项分条；信息密度优先。**

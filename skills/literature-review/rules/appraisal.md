# 方法学质量评估

对每篇纳入文献记录以下字段，汇总成表。

## 必记字段
| 字段 | 说明 |
| --- | --- |
| 研究设计 | RCT / 准实验 / 队列 / 横断面 / 案例 / 模拟 / 综述 / 立场文章 |
| 样本 | 规模、来源、代表性 |
| 对照 | 有无对照组、如何设置 |
| 结果指标 | 客观测量 vs 自报告 |
| 环境 | 实验室 / 现场 / 生产环境 |
| 资助方 | 独立 / 厂商 / 政府 / 未披露 |
| 可复现性 | 数据与代码是否公开 |

## 证据强度分级
| 级别 | 对应 |
| --- | --- |
| **强** | 多个独立的现场 RCT 或大样本队列，结论一致 |
| **中** | 单个设计良好的实验，或多个准实验结论一致 |
| **弱** | 小样本实验室研究、横断面调查、自报告为主 |
| **仅观点** | 立场文章、无数据的综述、厂商白皮书 |

## 常见陷阱
- **自报告效率提升**普遍高于客观测量，两者差距本身就是发现
- **实验室任务**与真实工作任务的差距要显式讨论
- **发表偏倚**：阴性结果更难发表，综述中阳性结论占比偏高是预期现象，要提示
- **新兴领域**的预印本未经同行评议，要单独标注

# 默认对比维度

按品类增删，但增删要在报告里说明理由。

## 必含
| 维度 | 要点 |
| --- | --- |
| 一句话定位 | 它自己怎么说，不是你怎么概括 |
| 目标客户 | 规模、行业、角色。看定价页分层和客户案例推断，并标注这是推断 |
| 核心功能 | 只列构成差异的，不列人人都有的 |
| 定价 | 档位、单位（席位/用量/一口价）、起步价、隐藏门槛、口径时间 |
| 部署形态 | SaaS / 私有化 / 混合；数据驻留地 |
| 集成生态 | 是否开放 API、主流系统的现成连接器 |
| 客户证据 | 实名案例、规模、可核实程度 |
| 公开弱点 | 有证据支撑的短板 |

## 按品类选含
- **开发者工具**：开源与否、许可证、自托管难度、社区活跃度
- **企业软件**：合规认证（SOC2/等保/ISO）、SLA、实施周期
- **AI 产品**：底层模型、数据使用条款、是否用客户数据训练、幻觉兜底机制
- **硬件**：供应链、交付周期、售后网络

## 填表纪律
- 同一维度上，各家必须用同一口径。口径不同就在格子里注明。
- 「未公开」和「不支持」是两件事，不能混为一谈。

# 公司健康度评估

## 0. 这个技能的定位与边界

**做什么**：把散落在公开信息里的经营压力信号收集、分级、交叉验证，告诉读者「这家公司现在处于什么状态、哪些指标在恶化、接下来该盯什么」。

**不做什么**：
- **不输出「这家公司会破产」这类断言。** 公开信息永远看不到现金余额和授信额度——那恰恰是决定生死的变量。一个看起来危险的公司可能明天拿到融资，一个看起来健康的公司可能因为单一客户流失崩盘。
- 不给投资建议（买入/卖出/做空）。
- 不基于传闻写负面结论。

**为什么这样划线**：对具名公司作出破产预言，既在法律上有风险（可能构成诽谤或市场操纵），在方法上也不成立。**有价值且站得住的产出，是「信号 + 证据 + 观察窗口」，不是一个二元结论。**

读者真正需要的是：现在能不能跟它签三年合同、该不该接这个 offer、要不要准备替代方案。这些问题用信号矩阵能回答，用破产预言反而不能。

## 1. 输入

公司名称。用户可能附带场景（供应商 / 求职 / 投资观察 / 合作），场景决定关注的时间窗：
- 供应商准入 → 未来 12–24 个月的交付稳定性
- 求职 → 未来 6–18 个月的裁员与发薪风险
- 投资观察 → 更长周期的结构性问题

先判断公司类型，两类的可得信息完全不同，走不同路径：
- **上市公司**：有强制披露，走财务路径为主
- **非上市 / 初创**：无强制披露，走间接信号路径为主

## 2. 执行步骤

1. **主体消歧**：锁定官网与注册主体。同名公司极多。
2. **判断类型与阶段**：上市 / 后期 / 成长期 / 早期。阶段决定什么信号算异常——早期公司裁员 10% 和上市公司裁员 10% 不是一回事。
3. **按 `rules/signals.md` 逐类扫描信号**。每个信号必须有可核验来源。
4. **交叉验证**：单一信号几乎没有判断价值。见 `rules/signals.md` 的组合规则。
5. **建立时间线**：把信号按时间排列。**趋势比快照重要**——一次裁员是事件，一年三次裁员是趋势。
6. **对照基准**：同行业同阶段的正常区间是什么。脱离基准谈"烧钱快"没有意义。
7. **给健康度评估**：分维度评级 + 整体判断 + 置信度 + 关键不确定性。
8. **给观察指标**：列出未来应该盯的具体、可观测的指标，以及「看到什么就说明情况在恶化 / 好转」。

## 3. 不可破坏的约束

- **不写「将破产」「即将倒闭」「撑不过 X 个月」**。可以写「公开信号显示 X 维度承压」「若 Y 在 Z 时间前未改善，交付连续性存在风险」。
- **每个负面信号必须有一手或两个独立可信二手来源**。单一媒体报道、匿名爆料、社交媒体传闻只能作为「待验证线索」单列，不进入评级。
- **区分「没查到」与「不存在」**。查不到融资记录不等于没融资。
- **必须写反面证据**。主动去找这家公司健康的证据（新客户、新产品、招聘回暖、正面财报），并呈现。只收集负面信号是确认偏误，会得出错误结论。
- **必须给置信度**。说明判断建立在多少条证据上、最大的信息盲区是什么。
- **财务推算要给公式**。从公开信息推测现金跑道时，必须写出计算式与每个假设，并标注这是估算。
- **员工个人信息不写**。裁员规模可以写，不写具体个人。
- 报告首尾必须有免责声明（模板已含）。

## 4. 典型误判

写报告前先读一遍，避免落进这些坑：

- **幸存者偏误**：看起来危险却活下来的公司不会上新闻，所以"危险信号"的历史命中率被高估。
- **融资沉默 ≠ 没钱**：很多公司刻意不公布融资。超过典型周期没有公开融资是信号，但不是结论。
- **裁员双向性**：裁员可能是失血，也可能是走向盈利的正常调整。要看裁的是哪些岗位、同期是否仍在招核心岗。
- **媒体放大**：知名度高的公司，同等问题会获得更多报道。报道量不等于问题严重度。
- **涨价双向性**：涨价可能是缺钱，也可能是产品力提升后的正常定价。看涨价幅度、方式（是否突然、是否针对存量用户）与同期产品变化。

# 压力信号清单与分级

逐类扫描。每条记录：**信号 / 证据来源 / 时间 / 强度 / 反向解释**。

## A. 资金与财务

### 上市公司（强制披露，证据等级最高）
| 信号 | 去哪看 | 强度 |
| --- | --- | --- |
| 审计报告出现持续经营重大不确定性（going concern） | 年报审计意见 | **极强** |
| 债务契约违约或豁免申请 | 公告、附注 | **极强** |
| 近期债务到期墙且再融资未落实 | 债务到期结构表 | 强 |
| 更换审计师（尤其是从四大换到小所） | 公告 | 强 |
| 撤回业绩指引 | 公告、电话会 | 强 |
| 经营性现金流连续为负且缺口扩大 | 现金流量表 | 强 |
| 收到交易所警示 / 退市风险提示 | 交易所公告 | **极强** |

### 非上市 / 初创（无强制披露，靠间接信号）
| 信号 | 去哪看 | 强度 |
| --- | --- | --- |
| 距上轮融资时间显著超过同阶段典型周期 | 融资数据库、新闻 | 中（需结合其他） |
| 下轮为 down round 或带清算优先权等结构化条款 | 媒体报道、公告 | 强 |
| 桥接贷款 / 内部轮（无新投资人进入） | 媒体报道 | 强 |
| 供应商或房东诉讼追讨欠款 | 裁判文书、法院公告 | **极强** |
| 社保/公积金缴纳人数骤降 | 公开企业信息平台 | 强 |
| 拖欠工资的多源报道 | 多个独立来源 | **极强** |

## B. 组织
| 信号 | 强度 | 反向解释 |
| --- | --- | --- |
| 12 个月内多轮裁员 | 强 | 单轮可能是正常调整 |
| 创始人或 CFO/CTO 等核心高管离职 | 强 | 也可能是正常换届，看接任安排 |
| 高管集中离职（3 个月内 ≥2 位 C 级） | **极强** | — |
| 招聘岗位数量断崖式下降 | 中 | 可能是招满了 |
| 办公场地退租 / 缩减 | 中 | 远程办公转型也会如此 |

## C. 业务与产品
| 信号 | 强度 | 反向解释 |
| --- | --- | --- |
| 砍掉主要产品线 | 强 | 也可能是聚焦 |
| 免费额度大幅收缩 / 突然对存量用户涨价 | 中 | 也可能是正常商业化 |
| 关键企业客户公开流失 | 强 | — |
| 服务质量下降的大量用户反馈 | 中 | 需排除单一事件 |
| 寻求出售 / 被收购传闻（多源） | 强 | 也可能是正常战略退出 |
| 核心团队被竞对 acquihire | **极强** | — |

## D. 外部环境
- 所在赛道整体融资降温
- 监管政策直接冲击主营
- 关键供应商或平台依赖断裂（如单一云厂商、单一模型供应商、单一渠道）

# 组合规则（关键）

**单一信号不构成判断。** 必须交叉验证：

| 组合 | 含义 |
| --- | --- |
| 融资沉默 + 裁员 + 高管离职 | 三类独立信号共振，压力较高 |
| 裁员 + 同期仍在招核心岗 | 结构调整而非失血 |
| 涨价 + 产品重大升级 | 正常商业化 |
| 涨价 + 服务降级 + 裁员 | 现金压力迹象 |
| 任一「极强」信号 | 可单独提示，但仍要找反面证据 |

# 反面证据清单（必查）

只找坏消息必然得出坏结论。必须同时检索：
- 新增实名客户、续约、扩容
- 新产品发布与迭代节奏
- 招聘是否回暖（尤其核心岗）
- 新融资、新战略合作
- 正面的第三方评测或行业奖项
- 管理层对质疑的公开回应

# 健康度评级

分维度给 **健康 / 观察 / 承压 / 高风险**，并给整体判断。

每个评级必须附：支撑证据条数、最强的一条反面证据、置信度（高/中/低）与理由。

**置信度为「低」时，整体判断必须相应保留**，不能用低置信度证据下高confidence结论。

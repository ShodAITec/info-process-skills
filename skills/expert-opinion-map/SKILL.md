# 专家观点图谱

## 输入

一个**存在实质分歧的议题**。

先判断议题是否适用：如果它其实有确定答案（只是用户不知道），直接给答案并说明，不要人为制造"两派"。**不给已有共识的问题强行搞平衡。**

## 交付

一张观点地图：谁主张什么、依据是什么、分歧的根在哪里。**不输出"所以到底谁对"的裁决**，但要输出「在什么条件下谁更可能对」。

## 执行步骤

1. **界定议题**：把模糊的争论收敛成一个或几个可辩论的命题。很多争论其实是在争不同的命题。
2. **识别阵营**：3–5 个立场群组。按论证逻辑分组，不按身份或机构分组。
3. **定位代表人物**：每个阵营找 2–3 位有公开、可引述论述的代表。**必须是真实可查的公开表述**。
4. **提取论证结构**：每个阵营的核心主张 → 论证 → 依据的证据或假设。
5. **定位真分歧**：见 `rules/disagreement.md`。这是本技能的核心。
6. **列出可证伪点**：什么样的证据出现会让某一方改变立场。
7. **标注演变**：有人改变过立场吗？为什么？

## 不可破坏的约束

- **引述必须真实且有出处**。每个观点要能对应到具体的文章、访谈、论文或公开发言，正文标注引用编号，完整链接与日期列入文末「参考来源」。**绝不可以根据某人的一般立场推测他在本议题上会怎么说。**
- **不做人身评价**。评论点是论证，不是人。不写「X 一向激进」这类定性。
- **不人为制造平衡**。如果证据强度悬殊，如实说明，不给边缘观点同等篇幅。
- **区分"事实分歧"与"价值分歧"**。前者可以用证据解决，后者不能——混在一起讨论是争论无解的常见原因。
- 标注观点的时间——人的立场会变，三年前的表述要注明时间。

## 引用格式

正文只写 `[N]` 编号，完整网址集中到文末 `# 参考来源`。详见 [citation_format.md](rules/citation_format.md)。

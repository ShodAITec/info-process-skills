# 分歧定位

争论看起来无解，通常是因为双方在不同层面分歧而不自知。逐层拆。

## 分歧的五个层面
| 层面 | 特征 | 能否用证据解决 |
| --- | --- | --- |
| **术语** | 同一个词指不同东西 | 能——定义清楚即可 |
| **事实** | 对世界现状的判断不同 | 能——取决于数据可得性 |
| **因果** | 同意现象，不同意机制 | 部分——需要特定研究设计 |
| **预测** | 对未来走向判断不同 | 只能等 |
| **价值** | 对什么重要的排序不同 | 不能 |

## 定位方法
1. 把各方主张写成命题
2. 逐个命题问：如果拿到某某证据，谁会改变立场？没人会改变的，就是价值分歧
3. **同一个争论里常常几层都有**——要分开列，否则读者会以为是一个问题

## 输出要求
明确写出：
- 哪些分歧是术语问题（澄清定义就消解）
- 哪些是事实问题（列出能裁决的证据类型）
- 哪些是价值问题（说明无法用证据解决，各方价值排序是什么）

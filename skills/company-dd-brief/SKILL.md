# 公司尽调简报

## 输入

一家公司的名称。用户可能附带用途（投资 / 合作 / 供应商 / 销售），**用途决定侧重点**：
- 投资 → 融资历史、股权结构、增长信号
- 合作 / 供应商 → 稳定性、交付能力、合规记录
- 销售 → 组织架构、决策链、采购信号、现有技术栈

用户没说用途就按通用模板走，并在开头注明。

## 交付

一份速查简报。目标是让读者在 10 分钟内掌握关键事实，并清楚**哪些没查到**。

## 执行步骤

1. **消歧**：先确认是哪家。同名公司很多，要锁定官网、注册地、统一社会信用代码 / 公司编号中至少一项。消歧失败就停下来问，不要赌。
2. **基础画像**：成立时间、总部、业务、规模（员工数来源要标注，领英自报与年报口径差异很大）。
3. **股权与融资**：轮次、金额、领投方、估值（估值几乎都是媒体口径，必须标注）。
4. **团队**：创始人与核心高管背景、近期高管变动（高管集中离职是重要信号）。
5. **客户与口碑**：实名客户、第三方评价、用户社区反馈。
6. **财务**：上市公司查财报；非上市只能拿到零散披露，**不要用营收推测利润**。
7. **法律与合规**：诉讼、行政处罚、知识产权纠纷、数据合规记录。查不到要区分「确认没有」与「没查到」。
8. **风险提示**：基于以上事实，列出需要进一步尽调的点。

## 不可破坏的约束

- **区分「没查到」与「不存在」**。公开渠道查不到诉讼，不等于没有诉讼。这两种表述的法律含义完全不同。
- **负面信息门槛更高**。诉讼、处罚、负面传闻必须有一手来源（裁判文书、监管公告、公司公告）或两个独立的可信二手来源。单一媒体报道只能写成「据 X 报道」，并注明未获证实。
- **估值与营收标注口径**。「据报道估值 X 亿」与「公司公告营收 X 亿」是两种证据等级。
- **人物信息克制**。只写与公司经营相关的公开职业信息，不涉及个人隐私。
- **不做投资建议**。可以陈述事实与风险，不写「值得投 / 不值得投」。
- 全程标注信息时间——尽调信息过期很快。

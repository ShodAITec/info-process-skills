# 他山见闻｜AI Research Digest Skill

当前版本：**v0.8.4**

产品形态：**“他山见闻”海外优质文章中文精读周刊**

标准交付：**一个 ZIP，内含同内容的 Markdown、可独立离线打开的 HTML，以及供 Markdown 使用的 `images/` 目录**

## 1. 用途

本 Skill 自动发现、核验、筛选并整合海外人文社科、商业管理、金融财务、经济与思想文化长文，生成面向国内相关专业读者的中文精读周刊。默认统计最近 7 天、目标入选 5 篇、全程自动执行。

它不做全文翻译、新闻摘要、技术或产业洞察，也不输出针对任何公司的行动建议。它与 Insight Analysis、任何企业背景以及无人机或机器人业务完全独立。

详细产品能力、文章来源、筛选和整期整合逻辑见 [用户功能说明书.md](用户功能说明书.md)。

来源是动态扩展的三层发现池，不限于某期出现的网站。每次运行从搜索开始分别记录检索站点、实际访问、可见搜索结果、已打开结果、去重后候选，再依次记录周期/来源/全文准入、质量判断和整期选文的剩余量及首要淘汰原因。文末附录用可对账表格呈现这些数据；无法从历史运行记录重建的数字明确标为未记录。

## 2. 调用方式

```text
使用 $ai-research-digest，筛选最近 7 天海外人文思想、商业管理和金融经济领域的优质文章，生成一期中文精读周刊。
```

用户也可以指定统计周期、主题、作者、来源、目标读者和篇数，或提供文章进入候选池。指定文章仍需通过全文核验与编辑筛选。

## 3. 默认规则

| 项目 | 默认值 |
| --- | --- |
| 周期 | 截至实际检索完成时间的最近 7 天；可按用户要求改为完整自然日 |
| 读者 | 国内人文社科、商业管理、金融财务、投资研究和思想文化专业读者 |
| 篇数 | 5 篇；不足时按实际数量发布 |
| 首页 | 标题为“他山见闻”；统一固定阅读说明提示块；展示内容周期及“撰文时间”，检索截止仅记在后台附录 |
| 深度 | 完整中文精读，不做全文翻译 |
| 配图 | 每篇 1 张；优先取原文中有使用许可的相关图片，并保留署名、来源、使用依据；无合适可用原图时由 AI 生成；单张不超过 2 MiB |
| 人工介入 | 无；普通异常自动处理并记录在文末 |
| 交付 | ZIP：一个 Markdown＋一个独立离线 HTML＋`images/` |

最重要的准入规则是：**找不到合法、完整的全文，就不做精读、不入选。**

## 4. 执行结构

`SKILL.md` 只保存执行契约和路由；阶段规则分别维护在：

| 文件 | 负责内容 |
| --- | --- |
| `references/discovery-and-selection.md` | 来源、候选池、去重、筛选与停止条件 |
| `references/evidence-and-copyright.md` | 全文准入、证据、版权与异常处理 |
| `references/editorial-template.md` | 周刊结构、单篇写法、中文风格与篇幅 |
| `references/visual-and-packaging.md` | 原图优先与 AI 回退、逐图署名图注、Typora、离线 HTML 与 ZIP |
| `references/run-record-schema.md` | 候选状态、筛选漏斗、时间与运行附录 |
| `assets/weekly-template.md` | 正式周刊骨架 |
| `scripts/render_offline_html.mjs` | 从定稿 Markdown 生成可独立离线阅读的 HTML |
| `scripts/validate_issue.js` | 交付前自动验收 |

## 5. 自动验收

Markdown 与配图定稿后，在技能目录依次运行：

```bash
node scripts/render_offline_html.mjs /absolute/path/to/AI_Research_Digest_YYYY_Www
node scripts/validate_issue.js /absolute/path/to/AI_Research_Digest_YYYY_Www
python3 scripts/package_issue.py /absolute/path/to/AI_Research_Digest_YYYY_Www
```

验收检查首页合并声明、内容周期、秒级“撰文时间”、文章模块与元数据、原文链接、每篇一图和两类图注、署名与许可字段、图片路径及大小、文末附录和“周刊”术语；同时检查 HTML 的 Markdown 哈希、逐张内嵌图像字节、所有引用 URL 纯文本、无 `<a>`/`href` 及离线资源依赖。最后一步重新验收并核对 ZIP 成员及解压后字节。图片许可须结合原始来源核实，脚本只能检查记录是否存在。HTML 可单独离线阅读；Markdown 的图片仍须连同 `images/` 移动。

HTML 链接呈现遵循“文章标题或来源名称一行，`原文网址：` / `引用网址：` 完整地址下一行”。URL 可选中复制，不做可点击跳转；Markdown 的原文标题等链接保持原来的写法。

写作时在加粗标签与后续内容之间留空格（如 `**来源：** Aeon`）；生成器兼容旧版行首标签，验收检查 HTML 可见正文没有裸露 `**`。原文网页上有图片不代表可在周刊 ZIP 和离线 HTML 中再分发；无具体使用依据时改用标明来源的 AI 示意图，并记录原因。

文末附录只记录定稿时已完成的事实；HTML 和 ZIP 的最终校验必须在定稿后运行，结果在交付说明中反馈。重新编辑 Markdown 或图片须重新生成 HTML 和 ZIP。断网浏览器实测若无法执行，应明确为“未验证”。

## 6. 版本维护

规则或行为变化同步更新其唯一负责的 reference、`SKILL.md`、README、用户说明书、`CHANGELOG.md` 和 `TODO.md`，发布时间精确到秒。回归时用实际旧刊副本检验；历史版本日志只追加。
